## This repository includes backlinks data for three in-language factchecking organizations in the U.S.
### Organizations: Factchequeado, VietFactCheck, and Piyaoba. 
### Backlink data collection tool: Link Analyzer provided by Moz.com
## Files include: 
(1) Nodes and edges dataset for Gephi use.  
(2) Subset analysis files: the files include network stats and edge and node lists broken down by each ego network, and depth of cralwing (Depth 1 and Depth 2)
